# FE06 — Streaming AI conversation

Conversation page: `/discovery` on the deployed application.

| Requirement | Implementation |
| --- | --- |
| Central server AI interaction | `src/app/api/chat/route.ts`: Google provider, `streamText`, UI message validation, request abort propagation, timeout and structured errors. |
| One commented model configuration | `src/lib/ai-config.ts`: model override and system prompt; key remains server-only. |
